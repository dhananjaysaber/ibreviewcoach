# Supabase Auth email templates

Paste into Supabase: Authentication > Emails > Templates.

| Template in Supabase | File | Subject line |
|---|---|---|
| Confirm sign up | confirm-signup.html | Confirm your email for IB IA Review |
| Reset password | reset-password.html | Reset your IB IA Review password |

The logo is loaded from https://ibiareview.com/email/logo-mark.png, so keep that file on the site.
Sender (support@ibiareview.com) is set under Authentication > Emails > SMTP Settings.
