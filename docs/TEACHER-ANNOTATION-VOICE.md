# Teacher annotated copy: moderator voice spec

Purpose: short annotations that read like an IB examiner/moderator marking a script, anchored to evidence, for IB submission.

## Rules for every annotation
- Max ~25 words. One idea per note. Third person about the work ("The candidate...") or impersonal ("Uncertainty not propagated").
- Always anchored to a quoted fragment of the student's text (max 15 words, verbatim) as evidence.
- Always tagged with criterion (RD / DA / CON / EVAL) and the band descriptor clause it supports or fails.
- Use IB command-term language: stated / identified / outlined / described / explained / justified.
- Neutral, factual, evidence-led. No praise padding, no advice to the student, no rewritten text, no exclamation marks.
- Credit and limit both: a "met" note names the clause achieved; a "limit" note names the clause not yet reached.
- Never state an official mark. Per criterion show only an indicative band (e.g. "DA: 3-4 indicated").
- Policy flags (word limit, raw data in body, ghost citation, identifying information) appear as a separate "Compliance" note type.

## Note types and example phrasing (illustrative, not data)
- Met: "RD: variables controlled and justified; method reproducible. Supports 5-6 clause: methodology allows full reproduction."
- Limit: "DA: uncertainty recorded for raw data but not carried into processed mean. Band 3-4 clause 'some consideration'."
- Gap: "CON: conclusion states a trend, not compared with accepted understanding. Needed for 3-4."
- Compliance: "Word count appears to exceed 3,200 excluding tables and graphs."

## End-of-script summary (one per criterion)
Indicative band + 2 bullet evidence references + the single clause most limiting the next band.

## Not allowed
Invented evidence, quotes not in the document, official-sounding marks, text written for the student.
